# LK Agent work umbrella

Generated artifacts from `/lyrikai-agent` sessions live here by default.

| Path | Purpose |
|------|---------|
| `archives/extractions/<slug>/` | re-app Way 2 extraction lanes |
| `products/<slug>/` | Product checkout — wiki, plan suites, gears |
| `templates/` | Optional raw donors (read-only) |

Override root via `LK_AGENT_WORK_ROOT` in `~/.lyrikai/config` (default: `$LYRIKAI_AGENT_ROOT/work`).

Path law: [`../WORK-HOME.md`](../WORK-HOME.md).

**Note:** `archives/` and `products/*/` contents are gitignored — structure only is tracked.
