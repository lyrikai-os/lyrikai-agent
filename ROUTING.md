# Lyrikai Agent — routing hallway

Master invoke: **`/lyrikai-agent`**. Opens **one** bundled companion (`/lk_*_v1`) per pass. Default posture: **WAIT** before irreversible steps.

**Work home:** read `WORK-HOME.md` on seat. Generated artifacts default under `$LK_AGENT_WORK_ROOT` (`work/`). Product research: `work/products/<slug>/admin/wiki/research/`.

Bundled invokes coexist with tip originals (`/re-app`, `/trinity`, etc.) — use bundled slugs when seated via this product.

---

## Signal → companion → stop line

| Signal | Open (bundled) | Stop line |
|--------|----------------|-----------|
| Unknown / first message | `lyrikai-agent` | Recommend one `lk_*_v1` + **WAIT** |
| Program rules, Hive cold-start | `lk_hive_v1` | Role + folder clear |
| Status / HOLD·GO / Queen overview | `lk_hive-queen_v1` | OVERVIEW + **WAIT** |
| Raw app / template reverse-engineer | `lk_re-app_v1` | RE-APP verify → `work/archives/extractions/<slug>/` |
| New idea / plan map / paper suite | `lk_build-plan-suite_v1` | END-GOAL under `work/products/<slug>/` |
| Product gears mint / refresh | `lk_gear-set_v1` | `.gears/` matches END-GOAL |
| Paper done → kickoff brief | `lk_handoff_v1 prep` (prefer over `lk_prep-prompt_v1`) | Brief only — separate build GO |
| Read-only phase audit | `lk_audit-prompt_v1` or `lk_handoff_v1 audit` | Audit prompt only |
| Helper bees / Hive delegates | `lk_hive-agents_v1` | Non-Admin helpers spawned |
| Build a slice (Trinity covenant) | `lk_trinity_v1` | Covenant disposition |
| Full unit → ship loop | `lk_super-build-trinity_v1` | Closeout gates |
| Mid-session fan-out | `lk_spin-agents_v1` | Under Queen + Trinity stack |
