## Install

**Canonical (public repo):**

```bash
git clone https://github.com/lyrikai-os/lyrikai-agent.git
cd lyrikai-agent
./agent/install/install.sh
./agent/install/verify.sh
```

See `agent/install/install.sh` for flags (`--dry-run`, `--cursor-only`, `--skills-only`, `--full-outer`).

**Prerequisites:** Tip skills checkout at `hive-vip-1/hive-vip-1_main/factory/skills/` — set `HIVE_TIP_SKILLS` if not under a sibling `lk-bloom` tree.

**Monorepo dev (optional):** if you already have `lk-bloom`, run from `lk-bloom/lyrikai-agent/` instead; publish changes to the standalone repo above.
